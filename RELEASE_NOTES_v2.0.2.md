# Master Report Center v2.0.2
Master Report Center by Golden Fir Solutions combines Split Reports, Consolidate Reports, Synchronize Reports and Lookup Data in one Windows desktop application.

## Release preparation changes
- Runtime logs moved to Local AppData.
- Imported configuration moved to Local AppData.
- Cloudflare licensing backend retained as the default remote licensing service.
- Windows COM dependency included in the release requirements.
- PyInstaller release build standardized on ONEDIR for cleaner Windows distribution and future MSIX packaging.
- Development logs, tests, cache files and obsolete build notes removed from the release source baseline.

## Requirement
Some Excel-preserving operations require Microsoft Excel desktop to be installed.
